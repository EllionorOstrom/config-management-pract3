# Ассемблер и интерпретатор УВМ (вариант 17)

Практическая работа №3 по дисциплине «Конфигурационное управление».
Реализовано этапов: 4 из 5.

## Общее описание

Проект содержит консольные приложения на Python 3 (только стандартная
библиотека) для учебной виртуальной машины (УВМ):

- **ассемблер** (`src/assembler.py`) переводит программу на языке
  ассемблера в промежуточное представление, затем в машинный код и
  записывает его в двоичный файл;
- **интерпретатор** (`src/interpreter.py`) читает двоичный файл,
  выполняет команды на модели УВМ и сохраняет дамп памяти в JSON.

## Спецификация УВМ

Команда занимает 4 байта (порядок байт little-endian). Поле A занимает
биты 0–6 и хранит код операции, поле B начинается с бита 7.

| Команда | A | Поле B | Действие |
|---|---|---|---|
| `LOAD_CONST` | 68 | биты 7–29: константа | кладёт B на стек |
| `READ` | 60 | биты 7–18: смещение | снимает со стека адрес, кладёт на стек значение памяти по адресу `адрес + B` |
| `WRITE` | 7 | биты 7–28: адрес | снимает значение со стека и записывает его в память по адресу B |
| `SUB` | 106 | нет | снимает со стека три элемента (см. ниже), записывает результат в память |

Вычитание `SUB` снимает со стека: первый операнд (вершина), второй
операнд и адрес результата. В память по этому адресу записывается
`первый операнд − второй операнд`. Поэтому перед `SUB` на стек кладут
сначала адрес, потом второй операнд, потом первый операнд.

Тесты из спецификации:

| Команда | Байты |
|---|---|
| `LOAD_CONST 152` (A=68, B=152) | `0x44, 0x4C, 0x00, 0x00` |
| `READ 316` (A=60, B=316) | `0x3C, 0x9E, 0x00, 0x00` |
| `WRITE 715` (A=7, B=715) | `0x87, 0x65, 0x01, 0x00` |
| `SUB` (A=106) | `0x6A, 0x00, 0x00, 0x00` |

## Язык ассемблера

Одна команда на строку: `мнемоника [аргумент]`.

- мнемоники: `LOAD_CONST`, `READ`, `WRITE`, `SUB` (регистр не важен);
- числа: десятичные (`152`) или шестнадцатеричные (`0x98`);
- комментарий начинается с `;` и идёт до конца строки;
- пустые строки пропускаются;
- команды `LOAD_CONST`, `READ`, `WRITE` требуют один аргумент, `SUB`
  аргументов не имеет;
- допустимые значения: `LOAD_CONST` 0–8388607, `READ` 0–4095,
  `WRITE` 0–4194303.

Пример:

```
LOAD_CONST 152   ; положить 152 на стек
WRITE 10         ; записать значение в ячейку 10
```

Ошибки (неизвестная мнемоника, неверное число аргументов, плохое число,
значение вне диапазона) выводятся с номером строки, код возврата 1.

## Ассемблер: запуск и настройки

```
python -m src.assembler <source> <output> [--test]
```

| Параметр | Назначение |
|---|---|
| `source` | путь к файлу с текстом программы |
| `output` | путь к двоичному файлу-результату |
| `--test` | режим тестирования |

Ассемблер записывает машинный код в `output` (недостающие папки
создаются), выводит размер файла в байтах. В режиме тестирования
дополнительно выводится результат в байтовом формате, как в тестах
спецификации (`0x44, 0x4C, 0x00, 0x00`).

## Интерпретатор: запуск и настройки

```
python -m src.interpreter <binary> <dump> --range START END
```

| Параметр | Назначение |
|---|---|
| `binary` | путь к двоичному файлу с программой |
| `dump` | путь к JSON-файлу с дампом памяти |
| `--range START END` | диапазон адресов дампа: от `START` включительно до `END` не включая |

Модель УВМ: память команд (байты программы) и память данных (список из
65536 ячеек) разделены; есть стек. Интерпретатор в цикле читает 4 байта,
переводит их в промежуточное представление и выполняет команду. Обращение
к адресу вне памяти данных, снятие со стека из пустого стека и неизвестная
команда дают ошибку `vm error`, код возврата 1.

Формат дампа:

```json
{
  "range": {"start": 100, "end": 102},
  "memory": [
    {"address": 100, "value": 11},
    {"address": 101, "value": 22}
  ]
}
```

## Описание функций

`src/isa.py`:

- `validate_operand` — проверяет, что значение помещается в поле B;
- `encode` — упаковывает команду в 4 байта машинного кода;
- `decode` — распаковывает 4 байта в команду.

`src/assembler.py`:

- `parse_number` — разбирает десятичное или шестнадцатеричное число;
- `parse_line` — разбирает одну строку программы;
- `assemble` — переводит текст программы в список команд;
- `to_machine_code` — переводит список команд в байты;
- `format_bytes` — записывает байты одной команды в виде `0x44, 0x4C, ...`;
- `write_binary` — записывает двоичный файл;
- `read_source` — читает исходный файл;
- `build_parser`, `main` — командная строка.

`src/interpreter.py`:

- класс `Machine` — модель УВМ (память команд, память данных, стек):
  `pop`, `cell`, `load_const`, `read`, `write`,
  `sub`,
  `step` (одна команда), `run` (весь цикл);
- `parse_int`, `check_range` — разбор и проверка диапазона адресов;
- `make_dump`, `save_dump` — дамп памяти в JSON;
- `read_binary`, `build_parser`, `main` — командная строка.
